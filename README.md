# CV Quest — a playable CV

A 2D side-scroller (Phaser 3) where visitors walk through your career: each school/job/project is a building
to enter, each skill is a coin to collect, and the castle at the end is your contact page.
A "📄 CV" button opens a classic, printable version for recruiters in a hurry.

## Edit your content
Everything comes from **`data.js`** — no need to touch the game code.

## Run locally
Just open `index.html` in a browser (no build step). Or: `python3 -m http.server` and visit http://localhost:8000

## Deploy
Static files only — drop the folder on GitHub Pages, Netlify or Vercel.

## Controls
← → / A D move · ↑ / W / Space jump · E / Enter enter building · on-screen buttons on phones
Click a timeline marker in the top bar to fast-travel.

## Classic page
The original plain CV page is still live at `/classic.html`.
